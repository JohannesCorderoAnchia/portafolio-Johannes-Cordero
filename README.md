# Portafolio de Johannes Cordero

Este es el repositorio del portafolio personal de Johannes Cordero, Ingeniero en Sistemas de Información con experiencia en desarrollo web Full Stack y soporte informático.

## Propósito

El proyecto tiene como objetivo presentar de manera profesional mi experiencia laboral, habilidades técnicas y proyectos destacados, facilitando el contacto para nuevas oportunidades y colaboraciones.

## Tecnologías Utilizadas

- **HTML5:** Estructura semántica de la web.
- **CSS3:** Estilos, animaciones, diseño responsivo (modo claro/oscuro incluido).
- **JavaScript (Vanilla):** Lógica para interactividad (e.g., cambio de temas con View Transitions API).

## Ejecución Local

Para visualizar el portafolio en un entorno local, sigue estos pasos:

1.  Clona este repositorio o descarga el código fuente.
2.  Abre la carpeta del proyecto en tu terminal.
3.  Inicia un servidor web estático. Por ejemplo, si tienes Python instalado, puedes ejecutar:
    ```bash
    python3 -m http.server 8000
    ```
4.  Abre tu navegador web y navega a `http://localhost:8000`.
